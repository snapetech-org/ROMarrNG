This packet contains 240 independent translation proposals for 20 sources across 12 locales, based only on the sealed blind input's English source and pinned caller contexts. The proposal ledger includes caller references, source hashes, rationale, confidence, and placeholder/numeric/markup/protected-literal checks for every cell. The blind-input verifier ran before generation and is rerun by verify_blind_review.py. Output files are pinned by manifest and SHA256SUMS.txt. Candidate-free input, glossary, and existing target/review material were not inspected. Native-speaker and browser review were not performed.

Run python3 verify_blind_review.py here to verify the blind input, all 240 row bindings, token checks, manifest hashes, and output checksums.
