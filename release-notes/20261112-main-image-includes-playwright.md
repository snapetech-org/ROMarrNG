The main ROMarrNG image now includes Playwright and Chromium; select Headless Browser and leave Browser Host blank, with no second ROMarrNG image or browser-server container needed. [@Ant1695](https://github.com/Ant1695) suggested the install issue in upstream ROMarr [issue #35](https://github.com/BlizzHacker/romarr/issues/35); ROMarrNG independently adapted the packaging.
