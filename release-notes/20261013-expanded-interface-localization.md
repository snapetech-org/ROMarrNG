The interface now supports twelve selectable languages, with translated navigation, settings, help, validation, and app-owned statuses. Arabic labels use right-to-left direction metadata within the left-to-right shell; full right-to-left layout support remains unreviewed. Date and number formatting remains separate; game titles, platform names, paths, API responses, and other user data retain their original text.
