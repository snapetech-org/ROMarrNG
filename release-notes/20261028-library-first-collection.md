ROMarr can start with the games you already own: map a local folder to its system, browse titles with covers, and discover missing games from DAT or IGDB catalogs. Catalog selections carry across pages, and ROMarr rechecks ownership before adding selected titles to Wanted. Configure download sources only when you choose to acquire games. Supported qBittorrent versions can use API-key authentication.

Set acquisition batches continue in the background after you close the page. Progress distinguishes requests accepted by a downloader from imports completed. If ROMarr stops while a request is in flight, the title is marked for review and is not retried automatically; check Activity and the download client before choosing to retry.
